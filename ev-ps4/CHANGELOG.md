# ev-ps4 CHANGELOG

2026-10-15 description 瘦身整改：version 变更日志从 SKILL.md frontmatter 下沉至此

## v1.2.3（PS4 先证者独立性核对，2026-10-16 用户复盘"争议实为跳步"）

- **根因**：评级实证——PS4 患者数未查 ClinVar SCV submission 详情，直接"3 提交≈3 无亲缘患者"推断。
- **第 1 步 AD/XL 补"先证者独立性核对"**：须核对各 SCV submission 是否无亲缘/独立，多个提交可能指向同一患者或同一家系，按患者/家系去重后再计数；无法确认独立按"疑同源（无法确认），保守合并"标注。先证者数逐篇核对、不重复计数。
- 纯流程/契约层改动，不改 VCEP 阈值表、不引擎。

## v1.1.0

- 新增遗传方式前置判定硬步骤——判定前必须先调用 `arad-inheritance-judgment` 确认该变异为 AD/XL 或 AR，再按对应分流规则（AD/XL 数先证者 / AR 用 OR），禁止默认遗传方式；遗传方式以 ClinVar 患者基因型+PubMed报道+GenCC MOI 三方交叉为准。

## v1.2.0

- 新增【文献核验+可疑文献上报】强制子步骤（PS4 全依赖文献先证者数/OR，每条文献先核验再计，ClinVar/HGMD挂载一律默认可疑）

## v1.2.1

- 补跨技能引用声明——凡本技能判定依赖文献检索/核验时，须调用 `ev-variant-literature-patient` 完成「可疑文献上报」与按用途差异化提取；本技能 description 显式声明该跨技能依赖，不再隐式引用。

## v1.2.2（全局维护收敛整改）

- 可疑文献判定完整标准（L1/L2/L3 分级 + 挂载默认可疑 + 强制上报）收敛到唯一权威 `ev-variant-literature-patient`，本技能仅保留按用途定制提取要求，不再内嵌重复完整段。
