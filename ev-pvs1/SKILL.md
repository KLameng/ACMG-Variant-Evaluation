# PVS1：功能丧失（LOF）型变异的非常强致病证据

## 定义（原文）

当一个疾病的致病机制为功能丧失(LOF)时，无功能变异（无义突变、移码突变、经典±1或2的剪接突变、起始密码子变异、单个或多个外显子缺失、基因内重复）。

**使用前提（四条注，原文）：**
1. 该基因的 LOF 是否是导致该疾病的明确致病机制；
2. 3' 端末端的功能缺失变异需谨慎解读；
3. 需注意外显子选择性缺失是否影响到蛋白质的完整性；
4. 考虑一个基因存在多种转录本的情况。

> PVS1 只用于已知是 LOF 致病的变异。遇到特殊基因，不要过度依赖框架，按其特有指南评级。

---

## 第 0 步：判断变异是否属于 LOF 型

LOF 变异包括（变异解读查询路径 5.3.1）：基因内重复（≥1 个外显子）、单个或多个外显子缺失、经典 ±1,2 剪接位点、无义/移码突变、起始密码子变异。
- 不属于上述类型 → 本证据不适用，返回总调度。

## 第 0.5 步：官方已定级优先（两级，识别步骤，供收尾唯一裁决；v1.10.2 收敛为一行引用）

> **本步骤只做"识别官方已定级（两级）"，** 最终裁决唯一在收尾 `acmg-conflict-summary-output` §0 前置【官方已定级优先（两级）】（含联网核实硬动作，v3.10.0 起），本技能不再内嵌完整规则、不做最终裁决。**两级识别**：
> ① 第一级：ClinGen VCEP/EP cspec 对本变异（具体到 c.HGVS/rsID）的官方裁定；
> ② 第二级：基因无 ClinGen cspec 时，存在权威专家组/官方技术标准共识性定级（CFTR2/ACMG 专项技术标准/ClinVar 专家评审 reduced-penetrance 等）。
>
> **采用规则（写死，与收尾一致）**：识别到官方/共识对**本变异**有裁定 → **最终分类优先采用官方/共识结论**；通用决策树算出的 PVS1 档位**不得覆盖**官方/共识结论（尤其对低外显率/可变外显率等位，如 CFTR 5T/TG12-5T，PVS1 不适用），差异在交付中显式标注。识别动作 + 联网核实 + 裁决均以收尾 §0 为唯一依据（详见收尾 SKILL）。

> **判例（写死，防复发）**：var006 GJB2 c.109G>A、var030 HBB IVS-II-654 官方均 Pathogenic——必须优先采用官方结论，不得走通用降成 VUS；var023 CFTR 5T 无 cspec 但有 CFTR2/ACMG 共识——优先采用共识，通用分值不得覆盖。

## 第 1 步：确定基因-疾病之间的关联

1. 在 OMIM 数据中查看基因与疾病的对应关系：https://www.omim.org/
2. 通过 ClinGen 查看基因与疾病的相关性，**等级需在中等以上（Moderate、Strong、Definitive）**：https://search.clinicalgenome.org/kb/gene-validity
   - **查证时须一并记录该基因-疾病对的三个字段（v1.5.0 强制）**：①分类等级（Definitive/Strong/Moderate）；②**遗传模式 MOI**（AD/AR/XL/semidominant）；③**致病机制 mechanism**（是否明确写 "loss of function"）。这三个字段是第 2 步机制确认和第 3 步决策树的前提，输出中必须列出。
   - 若基因-疾病关联不足中等 → PVS1 不适用。

> **⚠ gene-validity 官方档位缺失/未确认时回中间复核 + 条件定档（硬步骤，v1.10.0 起 / v1.10.2 改为条件定档，防取档偏松/偏高）**：若 ClinGen gene-validity 官方档位（Definitive/Strong/Moderate）**查不到或无法确认**（如官网不可达、条目缺失、分类未标注），**不得按 Strong/Definitive 类推升满档 VS**（实证 var028 CCDC88C：金标准 VUS，技能群在 gene-validity 档位未确认时按 Strong+PM2 组合类推取 LP，方法学取档偏松）。处理三步（**条件定档，不写死单一上限**）：
> 1. **回中间复核**：再走 ClinGen search.clinicalgenome.org、GenCC（gene-connection）、OMIM、已发表文献，尝试确认该基因-疾病对的有效性分类/MOI/mechanism 三字段；
> 2. **按关键区证据条件定档（v1.10.2，替代"一律封顶 Strong"）**：gene-validity 官方档位仍无法确认时，**先复核第 3.1 步关键区证据**——
>    - **关键区证据成立**（截断区关键，有下游热点/多病例/功能临床证据，经可疑文献 L3 核验）→ **PVS1_Strong（4 分，VUS 边界）**；
>    - **关键区证据确实查不到** → 据缺失蛋白长度定档（缺失 >10%→PVS1_Strong、<10%→PVS1_Moderate），并标注"关键区证据查不到，据缺失长度定档"；
>    - **仍不得升满档 VS（8 分）**：官方档位未确认时，满档的"Definitive/Strong 关联"前置不满足，无论关键区证据多强都**封顶 Strong**（对齐金标准口径，非"最高 Moderate"）；输出显式标注"gene-validity 官方档位未确认，取档受限，最高 Strong，不得升满档 VS"；
> 3. **不得以"PVS1_Strong + PM2_Supporting"组合类推 LP**：官方档位未确认时，组合取档须回落证据不足水平、回中间复核（对照收尾互斥/方向校验），防止偏高（var028 判例）。

### 第 1.1 步：ClinVar 截短变异计数（关联/机制判定核心方法，v1.4.0 新增）

> **判定"该基因 LOF 是否为已知致病机制"的实操方法：去 ClinVar search 页面筛选 P/LP 的截短（LOF）变异，数 ≥3 个。** 本方法适用于**所有遗传方式**（AR 病同样必须先过此关），是第 2 步 ClinVar 证据的具体操作化。

**操作步骤：**

1. 打开 ClinVar 搜索页：https://www.ncbi.nlm.nih.gov/clinvar/search/
2. 筛选条件：**基因 = 待评基因**（如 `ACD[gene]`）→ **Clinical significance = Pathogenic / Likely pathogenic** → **Molecular consequence = Frameshift / Nonsense / Splice site（移码、剪接等截短型）**；
3. **数截短变异个数**：统计符合"P/LP + 截短型（Frameshift+Nonsense+Splice site）"的变异条目数；
4. **判定**：
   - **≥3 个 P/LP 截短变异** → 该基因 LOF 为已知致病机制成立，进入后续 PVS1 判定；
   - **<3 个** → 机制证据不足，按 §2.1 强度调整降档或不适用；
   - **数不到/查不到** → 写"查不到"，不得以举例数据代替。
5. **记录**：在输出中写明"ClinVar 中该基因 P/LP 截短变异个数 = N"及筛选路径，作为关联≥Moderate/机制成立的证据。

> **铁律**：数的是**截短型（移码/无义/剪接）且 P/LP** 的变异个数，不数错义或 VUS。AR 病同样必须先过此关（跳过的是预测值评估，不是关联关）。

> **⚠ 文献核验 + 可疑文献上报（引用唯一权威）**
> **PVS1 判定中凡依赖文献的下游数据，须调用 `ev-variant-literature-patient` 完成「可疑文献上报」判定（L1/L2/L3 分级 + 挂载默认可疑 + 强制上报的完整判定标准，唯一以该技能为准）；其中 ClinVar 截短变异计数本身用官方分类、不依赖患者文献核验，正常执行；未核验到"该基因 LOF 为已知机制 / 截断点下游存在致病变异"具体事实的文献，不得用于 PVS1 档位判定。**
> **⚠ 按用途定制提取（v1.3.0 全局，PVS1）：本证据码从文献中必须提取【截断点下游已报道致病变异 + 下游热点聚集 + 关键功能区 + 病例数】；下游致病变异须在正文/表格核验到具体 c./p.，仅标题命中按可疑文献上报。ClinVar 截短变异计数本身正常执行，不触发文献上报。关键字段提取不到，标"查不到"，不得凭推测填充。**


## 第 1.5 步：遗传方式前置判定（硬步骤，v1.3.0 新增，PVS1 适用性的前提）

**判定 PVS1 前，必须先调用 `arad-inheritance-judgment` 子技能确认该变异的遗传方式（AD / AR / X连锁 / semidominant / 无法推断），禁止默认 AD 或 AR。** 遗传方式决定"LOF 是否为该基因的已知致病机制"及第 2 步的确认路径：

| 遗传方式 | LOF 机制确认路径 | PVS1 适用 |
|---|---|---|
| **AR（常隐）** | **仍须先过第 1 步关联关（ClinVar 数 ≥3 个 P/LP 截短变异，见下），跳过的是预测值评估（pLI/o/e/%HI，因隐性不适用）**——AR 病即双等位 LOF 致病，杂合 LOF 是明确机制变异 | **适用**（关联≥Moderate 确认 + NMD/关键区定档） |
| **AD-单倍剂量不足（AD-HI）** | 第 2 步做 HI/pLI/o/e/%HI 预测评估确认单倍剂量不足机制 | **适用**（杂合 LOF 即致病） |
| **AD-显性负效/功能获得（AD-DN/GOF）** | 第 2 步预测评估显示 LOF 非主要机制 → **反向排除** | **不适用**（错义致病，LOF 非机制） |
| **Semidominant（半显性）** | 按关联 MOI + LOF 机制确认（双等位致病明确；杂合外显率标注） | **适用**（外显率标注） |
| **X 连锁** | 半合子一个 LOF 即致病，机制明确 | **适用**（半合子/失活偏斜谨慎） |
| **无法推断** | 写"无法推断"，按证据不足处理，不得擅自假设 | 按证据不足 |

> **铁律**：遗传方式以 ClinVar 患者基因型 + PubMed 报道 + GenCC MOI 三方交叉为准，ARAD 为辅助检索工具（见 arad-inheritance-judgment 技能）。多模式基因（如 ACD 同时关联 AD+AR+semidominant）须明确该变异对应的关联疾病，不得笼统默认。**注意：遗传方式决定 PVS1 该不该用，但 PVS1 给档（满档/Strong/Moderate）仍由 NMD + 关键区 + 关联/机制强度决定，不因遗传方式自动升降。**

## 第 2 步：确定 LOF 是该基因的致病机制

> **⚠ 机制确认证据层级（强制，v1.5.0 新增——防"HI 剂量评分=0"误判"LOF 机制不成立"）**
> 判定"该基因 LOF 是否为已知致病机制"时，证据有**两个独立维度，不可混淆**：
> - **维度 A：基因-疾病有效性（gene-disease validity）** —— 去 ClinGen gene-validity 页查该基因的 Definitive/Strong/Moderate 结论。**若 ClinGen 明确写 "mechanism of pathogenicity is reported to be loss of function（致病机制为功能丧失）"，即为"LOF 是致病机制"的最高置信确认，直接支持 PVS1 使用。** 入口：https://search.clinicalgenome.org/kb/gene-validity ；Cross-Cutting 常用 GenCC：https://thegencc.org/
> - **维度 B：剂量敏感性评分（dosage sensitivity / 单倍剂量不足 HI）** —— 是"单倍剂量不足"这一**具体证据类别**的专项评分（0=无证据/未评分、1=极低、2=中、3=高）。
> **证据层级（强制）**：**维度 A（gene-disease validity 的 LOF 机制结论）优先于维度 B（HI 剂量评分）。**
> - **HI=0 或 "No evidence available" 只表示"单倍剂量不足这一维度未被单独评分/无证据"，绝不等于"LOF 不是致病机制"，不得据此否定 PVS1。** 例：ACD（TPP1，ClinGen Definitive，明确 "mechanism of pathogenicity is reported to be loss of function"，semidominant），即使 ClinGen 剂量敏感性 HI=0，LOF 机制仍成立，杂合无义变异 PVS1 可正常评估，**不得因 HI=0 而降档/弃用**。
> - 只有当**维度 A 也未确认** LOF 机制时，才按"机制证据不足"处理（见 §2.1 表）。
> - **操作路径**：第 1 步查 ClinGen gene-validity 结论时，**必须同时记录该基因的"MOI（遗传模式）"和"mechanism（致病机制）"字段**；若机制字段明确为 LOF，直接进入 PVS1 决策树；若为 dominant-negative / gain-of-function / 未注明，再结合维度 B 与 §2.1 判断。

按下列方法逐条确认（指南解读 slide 11-14；变异解读查询路径 5.3.1.2）：

1. **ClinVar 证据**：该基因在 ClinVar 中能查阅到已报道为致病或疑似致病的 LOF 变异（Frameshift、Nonsense、Splice site）——**按第 1.1 步方法，数 P/LP 截短变异 ≥3 个**（原始表述"数量至少为 2"，本技能按 SVI/ClinGen 官方校准升级为 ≥3 个更可靠）、和/或有基因敲除小鼠模型。https://www.ncbi.nlm.nih.gov/clinvar/search/
2. **OMIM 证据**：在 OMIM 该疾病的 Allelic Variants 目录中，查看是否报过多个致病 LOF 变异。
3. **单倍剂量不足（HI 剂量评分）**：显性遗传基因的 ClinGen 单倍剂量不足（HI）评分为 3。**注意：HI 评分只作补充佐证，HI=0 不得否定维度 A 已确认的 LOF 机制（见上方"机制确认证据层级"）。**
4. **预测值评估（仅显性遗传疾病；隐性遗传直接进入第 3 步）**：
   - o/e < 0.35（gnomAD）、pLI > 0.9（ExAC）、%HI < 10%。
   - 在 gnomAD 页面 http://www.gnomad-sg.org/ 查询 o/e、pLI；在 DECIPHER、ClinGen dosage 查询 %HI、pLI。
   - **注：如果 o/e 与 pLI 冲突，优先考虑 o/e；多数成年发病的疾病（如 BRCA1 pLI=0）不适用于 pLI、o/e 判断；该预测仅适用于表型严重的儿科疾病。**
5. **文献**：检索文献报道该基因的致病机制是 LOF。

**反向排除（指南解读 slide 11）**：ClinVar 中该基因只有 1–2 个 LOF 致病报道、致病证据又不充足，且 OMIM 中没有 LOF 致病相关报道 → 认为 LOF 不是该基因已知致病机理，**不用 PVS1**。

### 2.1 据以上证据的强度调整（指南解读 slide 14；变异解读查询路径 5.3.4.3）

| 条件 | 处理 |
|---|---|
| 基因-疾病有效性 Strong 或 Definitive，且 ≥3 个致病性 LOF 变异（未使用 PVS1 证据），且 >10% 的表型相关变异是 LOF（必须跨越超过 1 个外显子） | **用原证据等级** |
| 基因-疾病有效性 Moderate 及以上，且 ≥2 个致病性 LOF 变异（必须跨越超过 1 个外显子）和基因功能缺失小鼠模型 | **降一个等级** |
| 基因-疾病有效性 Moderate 及以上，且 ≥2 个致病性 LOF 变异（必须跨越超过 1 个外显子）**或** 基因功能缺失小鼠模型 | **降两个等级** |
| 无证据证明 LOF 是疾病致病机制 | **不适用** |

## 第 3 步：按 PVS1 决策树评级

### 3.0 先明确四个关键点

1. **NMD（无义介导的 mRNA 降解）如何判断**：位于 3' 末端的 LOF，即位于最后一个外显子 / 倒数第二个外显子的最后 50 bp，预测不会发生 NMD。判断方法：在 Mutalyzer 输入转录本及核苷酸变异，看对应 position 在第几个外显子。https://mutalyzer.nl/normalizer
2. **截断区域是否是蛋白关键功能区**：①通过文献确定截断区域功能（功能性实验或临床证据）；②在 ClinVar/HGMD/内部突变数据库查看截断区域**下游**是否存在致病位点（下游突变热点），存在则认为截断区域关键。注意：ClinVar/HGMD 致病性判断不能直接根据数据库报道，需自行评级确定致病性。
   > **⚠ 关键区判定须看"下游致病变异/热点+病例数"（v1.2 官方口径）**：判定截断区是否关键，核心证据是 **截断点下游是否聚集已报道致病变异（下游热点）+ 报道病例数 + 功能/临床证据**，而非仅看位置。有下游致病热点/多病例/功能证据 → 关键区；查不到 → 据缺失蛋白长度定档（>10%→Strong，<10%→Moderate）并注明"关键区证据查不到"。
3. **是否是生物学相关转录本**：查询 ClinVar 中致病突变的常用转录本；及该外显子中是否存在之前报道过的致病变异。
4. **特殊基因**：按其特有指南评级，可在 ClinGen 官网查看各专家组指南（RASopathy、CDH1、PTEN、Hearing loss、MYH7、PAH、DICER1、RUNX1 等）。

### 3.1 无义突变 / 移码突变（决策树，指南解读 slide 17）

1. 预测发生 NMD？（= 突变不位于最后一个外显子或倒数第二个外显子的最后 50 bp）
   - **是** → 该外显子在生物主要表达的转录本中存在？
     - 是 → **PVS1**
     - 否 → **不适用**
   - **否** → 突变位于蛋白的关键区域？
     - 是 → **PVS1_Strong**
     - 否 → **不适用**
     - 否/未知（= 实验证明该区域为关键区域，或该区存在非功能缺失性突变）→ 缺失序列中无 LOF 突变在正常人群中频繁出现、且所在外显子在生物主要表达的转录本中存在？
       - 否 → **不适用**
       - 是 → 缺失蛋白长度占蛋白总长度：
         - < 10% → **PVS1_Moderate**
         - > 10% → **PVS1_Strong**

**NMD 判定与档位复核（强制，v1.2 按 ClinGen SVI 官方校准）**：

> **⚠ 核心原则（v1.2 硬约束）：「位置不是绝对评级」。** 末外显子/深内含子等位置只是判定**起点**，最终档位必须综合下列四维整体评估，不得仅凭"末外显子→Strong"或"深内含子→Strong"机械定档。

1. **NMD 位置判定须用外显子 rank 核对（MANE 转录本）**：用 VEP/GeneBe 基础注释取该变异的 `exon_rank` / `exon_count`，判断是否位于最后一个外显子或倒数第二外显子的**最后 50 bp**。**不得凭蛋白位置/氨基酸序号估算**（ERCC4 p.Gln206* 在 exon 4/11 远非末位，预期 NMD，应满档 PVS1，勿误降 Moderate）。
   - NMD 不预测的情形（官方定义）：终止密码子位于 **3' 最末外显子** 或 **倒数第二外显子的最后 50 nt**（Chang 2007；Lewis 2003）。**注意：这是"进入整体评估"的起点，不是"自动给 Strong"的终点。**

2. **当 NMD 不预测时（末外显子/最后 50bp），档位整体评估（强制，v1.2 新增；v1.9.0 升级为强制闭环硬步骤）**
   > **⚠ v1.9.0 强制闭环（防"规则写了但执行没搜、保守落 Strong"——实证 var032 CNGA3：SKILL.md 判例写明该升满档，实际评级却停在 Strong）：末外显子无NMD 变异，档位判定前必须走完「①下游热点穷尽检索 → ②判定闸 → ③查不到才降」三步，缺一步不得定档。不再允许"查了再说 / 不查直接按长度定档"。**
   - **① 强制下游热点穷尽检索（硬步骤，v1.9.0 写死）**：凡 NMD 不预测的末外显子/最后 50bp 变异，**必须**在 **ClinVar / HGMD / 文献(PubMed)** 三通道检索截断点**下游**是否聚集已报道致病变异（下游热点），并**必须输出"下游热点检索结果表"**：`| 下游致病变异(c./p.) | 来源(ClinVar/HGMD/PMID) | 独立变异数 | 病例数/病例来源 | 功能/临床证据 |`，表中每项查不到写"查不到"。**不得**以"已判关键区/非关键区"为由跳过检索，**不得**不查直接按缺失蛋白长度定档。
   - **② 判定闸（写死，v1.9.0）——达条件必须升满档，禁止保守停在 Strong**：
     - **升满档前置（v1.10.0 补，堵激进面）：下游热点每个独立致病变异必须先过「可疑文献上报」L3 核验**——ClinVar/HGMD 挂载的文献一律默认可疑，须逐条全文核验到该具体下游变异（或输出 PMID+链接+原因 上报人工核验）后才可作为"下游热点"计入满档计数；**未过 L3 核验的下游变异不得计入 ≥3 个阈值**。仅当三通道检索到且均经 L3 核验，才进入下方触发。
     - **截断区关键 + 下游存在 ≥3 个独立致病变异（热点，均经 L3 核验）+ 多病例报道 + 有功能/临床证据证实该区关键** → **必须升满档 PVS1（8分）**，并注明"下游热点+病例数+功能证据充分，按 v1.9.0 判定闸升满档"；**不得因"保守/位置末外显子"停在 Strong**。
     - **判例（写死，防复发）**：var032 CNGA3 c.1495C>T（p.Arg499*）下游 p.Arg569 有 5 个独立致病变异（PMID 11536077/17693388/24148654/26493561/30337596）+ 多病例（PMID 26992781/29618791/24903488）→ **必须升满档 PVS1**，禁止停在 Strong。
     - **截断区关键但下游热点/病例数未达满档阈值**（如仅 1-2 个下游致病变异、或查不到多病例）→ **PVS1_Strong**（官方证据权重 ~19:1），并标注"关键区成立但下游热点/病例不足升满档阈值"。
     - 官方先例（佐证，非唯一判据）：PTEN 工作组把末外显子无NMD但**关键区（C端功能域：PEST基序/磷酸化位点/PDZ结合域）且证实 LOF** 的截短变异从 Strong 升满档；GAA 起始密码子（1-122缺失产生无功能蛋白）亦升满档——升满档前提统一为"截断区关键（下游热点+病例+功能证据）"，判定闸量化见上。
   - **③ 查不到才降（v1.9.0 写死）**：仅当"下游热点三通道穷尽检索"全部走完、**关键区证据确实查不到**（无下游致病变异 / 无功能临床证据可核验）时，才据缺失蛋白长度定档：
     - 缺失 >10% 蛋白 → **PVS1_Strong**；
     - 缺失 <10% 蛋白 → **PVS1_Moderate**；
     - 缺失外显子富集高频人群 LOF 变异 或 不在主要生物转录本 → **不适用**；
     - **且必须标注"关键区证据查不到，据缺失长度定档"**，不得静默按长度定档。
   - **非关键区（已按①→③确认截断区非关键）** → 按上述③缺失蛋白长度占比分支定档。
   - **铁律（v1.9.0）**：不得仅凭"位于末外显子"就给 Strong/Moderate；末外显子无NMD 变异档位必须先走"①穷尽检索 → ②判定闸 → ③查不到才降"三步闭环，任一 步未执行或未输出对应检索表/标注即视为违规，须回补后再定档。

3. **PVS1 满档（VeryStrong）的基因-机制前置（官方 Table 1，v1.2 校准）**：
   - PVS1 满档**仅限**：基因-疾病有效性 **Definitive 或 Strong**，且 LOF 变异占该基因报道致病变异 **≥10%**，且 **≥3 个**非依赖 PVS1 判定的致病 LOF 变异。
   - **Moderate 关联基因**：即使截短变异预期 NMD，**最高只给 PVS1_Strong**（官方："no higher than PVS1_Strong should be assigned for a LoF variant in a gene with moderate disease evidence where only two LoF variants have been reported"）；再降档情形按 §2.1 表。
   - 预期 NMD 的截短变异，在满足上述满档前置时**给满档 PVS1（8 分）**，不得保守降档；不满足满档前置（如 Moderate 关联/LOF 变异占比不足）时给 Strong，并说明"因基因机制强度不足而满档受限"。

4. **剪接预测取数通道（v1.11.0 接入 SpliceAI2，基础注释取数+来源版本绑定）**：剪接区（±1,2 / 深内含子 / 隐蔽剪接 / 非编码）变异判定前，优先用 **SpliceAI2** 评估剪接后果——`spliceai2_summary_score`（0-1）阈值 0.1=高召回、0.25=平衡、0.5=高精度，对应初代 SpliceAI 0.2/0.5/0.8（Jaganathan 2019）；来源版本绑定：SpliceAI2 v2, Illumina BioInsight AI Lab, 2026-10-08（technical article + manuscript preprint）, github.com/Illumina/SpliceAI2, 预计算 40 亿 SNV + 1.5 亿 indel 学术免费；初代 PMID 30661751。SpliceAI2 不可达/无 GPU 时回退初代 spliceailookup 官方 API 0.2 高召回切点并交叉验证。深内含子隐蔽剪接是初代灵敏度短板（SpliceAI2 约半数隐蔽剪接位点位于 >50bp 深内含子，外显子测序常漏），优先 SpliceAI2 可降低漏判。SpliceAI2 只做剪接预测取数，**不替代 RNA 实证（RT-PCR/RNA-seq，归 PVS1_Strength(RNA)）与成熟功能实验（PS3/BS3）**。

5. **剪接区变异档位（非 ±1/2，v1.2 校准）**：档位取决于**预测的剪接后果**（含 SpliceAI2/初代剪接预测）与 **RNA 实证**，而非"非±1/2=Strong"：
   - **预测造成移码 + NMD** → 按 NMD 决策树给满档/Strong；
   - **RNA 实证（RT-PCR/RNA-seq）证实破坏阅读框/引入提前终止/假外显子** → 按 **PVS1_Strength(RNA)** 给档（Splicing Subgroup：RNA 实证 LOF 用 PVS1_Strength 捕获）；如 SLC12A3 c.2521+253C>T 假外显子+提前终止 → PVS1_Strong；
   - **框内剪接 / 不触发 NMD / 外显率降低型**（如 CFTR 5T/TG12-5T）→ **不得用 PVS1**；
   - **PS3/BS3 仅用于成熟功能实验**（非 RNA 剪接实验直接测得者），RNA 剪接实证按 PVS1_Strength(RNA) 归 PVS1，不叠 PS3。

6. **深内含子变异的整体评估（v1.2 补充，结合 SpliceAI2 剪接预测）**：深内含子/非±1/2 剪接变异不得仅因"位置深"就判 Strong 或不适用，须查：①是否有 RNA 实证（假外显子/滞留/跳跃）；②激活隐蔽剪接后是否移码+NMD（**优先用 SpliceAI2 预测，v1.11.0**）；③下游是否热点/病例；④人群频率（gnomAD LoF 富集则降权）。综合后定档，并在输出逐一注明各维度查到/查不到。

> **🔧 确定性剪接影响判定（acmg_evidence.py，替代手工阈值；阈值权威来源=config/thresholds.json → `spliceai.v2_thresholds`）**：SpliceAI2/初代分数→剪接影响判定统一用 `scripts/acmg_evidence.py` 的 `spliceai_band(score, version)`（v2：0.1/0.25/0.5 三档；v1：>0.2 高召回，阈值读 config，改 config 即逻辑与打印同步，不硬编码）。用法：`python acmg_evidence.py spliceai_band <score> v2`；分数取不到写"查不到"，不得默认无影响。

### 3.2 经典剪接位点突变（指南解读 slide 18；决策树同 3.5 缺失树）

- 经典剪接位点默认造成紧邻外显子缺失，需判断是否造成移码突变。
- 判断方法：
  1. 通过 Auto_pvs1 查询协助判断：https://autopvs1.bgi.com/
  2. 评估受影响外显子长度是否造成移码：查看"变异临近外显子碱基数是否是 3 的倍数"。若受影响外显子是 3 的倍数，需再考虑受影响外显子大小（占蛋白全长比例）及是否为功能区。
  - 示例：SLC26A4 (NM_000441.2):c.919-2A>G，Exon8 长度 83 个碱基，非 3 的整倍数。
- **避免与 PP3 同时使用**。

### 3.3 单个/多个外显子缺失（决策树，指南解读 slide 19）

- 先确认突变剪切位点 +/−1,2 的位置；其他剪切位点序列可能出现重新恢复框内剪切。
- **整个基因缺失**：确定基因具有单倍剂量不足效应且无反对证据 → **PVS1**。无冲突情况下，对整个基因缺失，如果剂量不足，可直接评为可能致病，不用凑证据。
- **单个/多个外显子缺失**：评估缺失是否造成移码，以及是否为临床相关转录本。
  - 开放阅读框改变 → 走与 3.1 相同的 NMD / 关键区域 / 缺失长度分支（PVS1 / PVS1_Strong / PVS1_Moderate / 不适用）。
  - 开放阅读框不改变：如果单个或多个外显子缺失发生在最后两个外显子，按"缺失不改变阅读框"判定 → **PVS1**。

### 3.4 起始密码子突变（决策树，指南解读 slide 20）

- 是否存在其他转录本中有不同的起始密码子？
  - 是（数据库/文献核实存在其他功能转录本使用其他起始密码子）→ **不能使用 PVS1**
  - 否 → 基因内另外的 ATG 密码子的上游是否有 ≥1 个致病变异位点？
    - 是 → **PVS1_Moderate**
    - 否 → **PVS1_Supp**
- 起始密码子突变证据强度**最高到 PVS1_Moderate**。

### 3.5 基因内重复（决策树，指南解读 slide 21）

- 重复必须完全包含在基因内，且大小 ≥1 个外显子；重复片段长度要确定，否则无法适用此标准。
- 如果重复中包含了最后一个外显子，则不适用 PVS1。
- 是否为串联重复（in tandem）？（文献显示至少 83% 的重复是串联重复）
  - 否 → **不适用**
  - 是 → 开放阅读框改变且预测发生 NMD？
    - 是 → **PVS1**
    - 否/未知 → **不适用**
    - 推测是 → **PVS1_Strong**
    - 推测否/未知 → **不适用**

### 3.6 特殊情况（指南解读 slide 22）

PVS1 是框架，遇到特殊基因仍需特殊考虑，不要过度依赖框架：
- GAA NM_000152.4:c.1A>G 按框架为 PVS1_Moderate，但因丢失 1–122 密码子产生无功能蛋白，评为 PVS1。
- PTEN 最后一个外显子不发生 NMD，但功能域非常关键，PTEN 工作组建议 PVS1。
- 特殊基因按其特有指南评级（ClinGen 官网各专家组）。

## 输出格式（强制，本 SKILL 判定完成后必须按此输出）

每个证据码判定完成后，**必须**按下述三点完整输出；缺一不可，查不到的数据明确写 **"查不到"**，严禁用本 SKILL 内的举例数据或推测代替。

### 1. 证据码 + 对应等级
`[证据码]_[使用等级]`，如 `PM3_Strong`、`PP3_Moderate`、`PM2_Supporting`。未成立则写"本证据不成立/弃用"。

### 2. 支持该等级使用的规则性数据内容 + 定级规则
- 写明支撑该等级判定的**具体数据值**（如人群频率、REVEL 分数、反式例数、对照数目、OR 值、分离次数等）；
- 对照本 SKILL 的定级规则/阈值表，说明该数据落在哪个区间/档位，从而定为该等级；
- 即：数据值 → 落入的规则档位 → 所得等级，三步闭环。

### 3. 查询路径
列出本次判定**实际查询过**的数据库链接、文献编号(PMID)及对应链接；**每次查询都必须是真实查询**。
- 数据库：名称 + URL（如 ClinVar、gnomAD、Pubvar、OMIM、HGMD、ClinGen 等）；
- 文献：PMID 编号 + 链接；
- 某项查不到：写 **"查不到"**，不得以举例数据填充。
