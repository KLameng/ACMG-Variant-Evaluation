- **Strong** ✅：Use the PP4 table (see supplementary file “PP4 table SGCD”) to determine the appropriate PP4 strength level. Apply PP4 only once, for a patient meeting the highest possible strength level. When applied together, PP1 and PP4 cannot exceed 5 Bayesian pts (Supporting + Strong or Moderate + Moderate).
- **Moderate** ✅：Use the PP4 table (see supplementary file “PP4 table SGCD”) to determine the appropriate PP4 strength level. Apply PP4 only once, for a patient meeting the highest possible strength level. When applied together, PP1 and PP4 cannot exceed 5 Bayesian pts (Supporting + Strong or Moderate + Moderate). If PP1\_Moderate is applied and the criteria for PP4\_Strong are also met, a downgraded PP4\_Moderate can be applied.
- **Supporting** ✅：Use the PP4 table (see supplementary file “PP4 table SGCD”) to determine the appropriate PP4 strength level. Apply PP4 only once, for a patient meeting the highest possible strength level. When applied together, PP1 and PP4 cannot exceed 5 Bayesian pts (Supporting + Strong or Moderate + Moderate).
