# ClinGen VCEP 基因特异性变异评级规范

## 1. 数据包与路径

本 Skill 的本地数据来自两个 ClinGen-VCEP 压缩包（云盘导出），已解压到 Skill 目录下：

| 数据包 | 位置（相对本 Skill） | 内容 | 规模 |
|--------|----------------------|------|------|
| **知识库** | `knowledge-base/` | 每基因一份合并规范 `VCEP-<基因>.md` + 索引 + 验证/审查报告 + ClinGen 官方附件 | 435 文件 / ≈60 MB |
| **叙事单元** | `narrative-units/` | 按证据码类别切分的细粒度 markdown 片段，供 RAG 检索 | 1721 文件 |

数据日期：**2026-06-13**（知识库规范正文）与 **2026-06-14**（验证报告）。
来源：ClinGen SVI Criteria Specification Repository（cspec.genome.network）。
⚠️ 本数据为智能分析整理结果，**仅供参考**；临床变异评级请以 ClinGen 官方最新版本为准。

### ⚠ 版本绑定与过期守卫（硬步骤，v1.1.0 强制，整改 clingen-vcep D6⑩ 不达标）

本技能为**本地 cspec 快照**，必须执行过期守卫，禁止静默用旧版规则定级：

1. **每次使用先核对快照日期**：本快照数据日期 **2026-06-13**。判定前先记录当前日期，计算快照距今间隔。
2. **过期触发闸（写死）**：快照距今 **>180 天** 或该基因 cspec **已发布新版本**（可联网到 cspec.genome.network 核对）时，**必须**在线复核该基因的 ClinGen 官方最新版规范；核对结果为"官方已升版/内容已变"→ 以官方最新为准并记录来源+版本+日期；"官方无更新"→ 可沿用本地快照并标注"已在线复核，官方当前无更新（日期）"。
3. **不可静默定级**：不得在未核对快照日期的情况下直接采信本地数据定级；快照过期但未在线复核 → 该基因规范标注"**快照过期，待官方复核**"，不得作为唯一判据。
4. **终审边界**：本地数据仅作判读引导，**最终评级一律以 ClinGen cspec 官网最新版为准**；本地与官网冲突时官网优先。

### 1.2 叙事单元（`narrative-units/`）结构

扁平目录，1721 个 markdown，命名规则：

```
VCEP-<基因前缀><类别后缀><序号>.md
```

类别后缀（重要，用于检索定向）：

| 后缀 | 含义 | 示例 |
|------|------|------|
| `a` | 概述与疾病（覆盖疾病、遗传方式、通用说明） | `VCEP-BRCA1a_概述与疾病01.md` |
| `b` | 致病性证据（PVS1、PS1-4、PM1-6、PP1-5） | `VCEP-BRCA1b_致病性证据03.md` |
| `c` | 良性质证据（BA1、BS1-4、BP1-7） | `VCEP-BRCA1c_良性质证据.md` |
| `d` | 参考附件与链接（cspec 官方文件链接） | `VCEP-BRCA1d_参考附件与链接.md` |

每个叙事单元头部含 `来源 / 数据日期 / 原文提取方式`，正文为"规范 N：GN### — VCEP 专家组名称"片段。

**索引/说明类片段**：另有 `VCEP-IDX*_*.md` 共 8 个（说明与概览、VCEP 专家组、基因字母索引等），属导航性内容，不承载基因规范。

> **检索建议**：RAG/向量检索优先用叙事单元（细粒度、按证据码定向）；需要某基因完整规范或附件时直接读 `knowledge-base/VCEP-<基因>.md` 与 `knowledge-base/knowledge-base/attachments/`。

### 1.3 基因→GN→文件映射表（确定性路由核心）

为支持"方式 B 按路径确定性读取、不跳过该用文件"，本 Skill 内置三份映射表（与数据文件逐一比对生成，覆盖全部 131 基因、296 附件）：

| 文件 | 用途 |
|------|------|
| `gene-gn-file-mapping.md` | 人读主表：基因 → GN 编号 → VCEP 专家组 → 知识库文件 → 叙事单元数 → 附件数 |
| `gene-gn-file-mapping.csv` | 机器可读主表（同字段），供脚本/智能体路由查表 |
| `attachment-index.csv` | 附件明细：基因、GN、附件文件名 |

**使用规则**：评级任意基因时，先查映射表确定该基因的全部 GN 与对应文件，再按表逐一读取，杜绝漏项。

**多规范基因（必须读取全部规范）**：映射表已标"多规范=是"——
- `ACTA1`：GN147 + GN169（两个规范）
- `RYR1`：GN012 + GN150 + GN179（三个规范）
- `VWF`：GN081 + GN090（两个规范）

这类基因只读 `VCEP-<基因>.md` 中某一个规范会漏掉另一套证据码规则，必须通读文件内全部"## 规范 N"小节。

## 2. 触发与适用场景

本 Skill 在以下场景使用：

1. **基因特异性规范查询**：用户给出基因名/基因符号（如 BRCA1、SCN8A）或 GN 编号，需要其 VCEP 已批准/已发布的基因特异性评级规则。
2. **变异逐码判读**：用户给出一个具体变异（HGVS 或 rsID），需要按 ACMG 证据码逐条判读，并用该基因的 VCEP 特异性阈值/积分表而非通用 ACMG 规则。
3. **证据码阈值核对**：查询某证据码（如 PVS1、PM2、BA1）在某基因下的强度层级、频率阈值、REVEL/CADD/SpliceAI 分数界值、积分规则。
4. **评分表/决策树附件获取**：需要某个 VCEP 的 PP4 积分表、PM3 积分指导、PS2/PM6 表、PVS1 决策树、功能检测方法等官方附件。
5. **不适用证据码确认**：判断某证据码在该基因 VCEP 中是否"不适用"（Not Applicable）及原因。
6. **评级依据解释**：需要给出 ClinGen 官方口径下的评级依据和可解释说明。

**不适用的场景**：不用于纯基因-疾病相关性（gene-disease validity）查询；不用于无 VCEP 规范基因（如 COL1A1、TSC2、LMNA）的 VCEP 特异性规则；不用于临床诊断决策、治疗建议或保险判断；不以本地数据替代 ClinGen 官网最新版作为终审依据。

## 3. 核心工作流

### 步骤 0：确认基因是否有 VCEP 规范

- 用 `00-索引.md` 或 `knowledge-base/` 目录确认基因是否存在对应 `VCEP-<基因>.md`。
- 若基因在索引与目录中均不存在（如 COL1A1、TSC2、LMNA），**明确告知用户该基因无独立 VCEP 规范**，不臆造规则。
- ⚠️ 注意核实报告发现的**历史 GN 编号错配**：GN 编号必须与基因对照确认，勿凭记忆使用（见第 5 节）。

### 步骤 1：定位规范来源（先查映射表，再取文件）

- **首步必做**：查 `gene-gn-file-mapping.csv/md`，确认该基因的 GN 编号、知识库文件、叙事单元数与附件清单，按表取文件——这是避免跳过该用文件的确定性保证。
- **多规范基因**：映射表标"多规范=是"的（ACTA1、RYR1、VWF），必须读取 `VCEP-<基因>.md` 内全部"## 规范 N"小节，不可只读其中一个 GN。
- **快速全量**：`knowledge-base/VCEP-<基因>.md` —— 一个文件含该基因全部证据码、阈值、附件链接。
- **定向检索**：按需在 `narrative-units/` 中按 `<基因>a/b/c/d` 定位概述/致病证据/良性证据/附件片段。
- **附件原件**：`knowledge-base/knowledge-base/attachments/GN<编号>_*.xxx`，文件名以映射表 `attachment-index.csv` 为准，按关键词匹配（如 `PVS1_DecisionTree`、`PM3_table`）。

### 步骤 2：逐证据码判读（核心）

每个 VCEP 规范的证据码条目固定包含以下字段，判读时逐项对照：

```
#### <证据码>
- 默认强度：Pathogenic/Benign <Very Strong|Strong|Moderate|Supporting|Stand Alone>
- ACMG原始定义：<Richards et al. 2015 的通用定义原文>
- Caveats/Notes：<使用注意，如 LOF 机制、3'端、剪接、多转录本等>
- <强度层级> ✅：<该基因特异性的阈值/判读条件>   # ✅ 表示已 approved
```

判读要点：
- **强度层级由证据码确定**：同一证据码可拆分为不同强度（如 PVS1 从 Very Strong 到 Supporting；PM3 从 Very Strong 到 Supporting），按该基因给出的 ✅ 条件判定实际可用强度。
- **只采用带 ✅ 的 approved 条件**；未 approved（📋）的仅作参考，不据此终审。
- **不适用证据码**：条目底部或"### 不适用证据码"列出，判读时若命中直接判为不适用并引用原因。
- **点积分制（point counting）**：部分 VCEP（如 ABCA4、SCN8A）采用 Tavtigian 积分制替代规则组合，需用对应积分表（PS2/PM6、PM3、PS4、PP4）累分定强度。
- **互斥规则**：注意基因特异性互斥条款（如 PVS1 与 PP3 不并用；PM5_Strong 与 PM1 不重复计分；PP1 与 PP4 组合封顶），防止重复计分。

### 步骤 3：整合评级输出

输出格式建议（供参考，可按用户要求调整）：

1. **基因与规范来源**：基因符号、GN 编号、VCEP 专家组名称、本地数据日期。
2. **变异与判读**：HGVS/rsID、拟判定变异。
3. **证据码清单**：逐码给出【适用/不适用】+【强度】+【该基因特异性依据（引用原文阈值/积分）】，标注 ✅。
4. **评级结论**：Pathogenic / Likely Pathogenic / VUS / Likely Benign / Benign 及其依据。
5. **不确定性**：数据缺失、官网版本差异、需人工确认项。

## 4. ACMG 证据码速查

| 类别 | 证据码 | 通用含义 |
|------|--------|----------|
| 致病性-极强 | PVS1 | 无功能变异（LOF） |
| 致病性-强 | PS1-PS4 | 同氨基酸改变 / de novo / 功能研究 / 患病群体富集 |
| 致病性-中等 | PM1-PM6 | 突变热点/功能域 / 群体频率 / 反式排列 / 蛋白长度 / 同一位点不同错义 / de novo |
| 致病性-支持 | PP1-PP5 | 家系共分离 / 病例对照 / 计算预测 / 表型特异 / 可信数据库 |
| 良性-独立 | BA1 | 等位基因频率 >5% |
| 良性-强 | BS1-BS4 | 频率过高 / 功能研究无影响 / LOF无意义 / 缺乏共分离 |
| 良性-支持 | BP1-BP7 | 错义为常见病因 / 良性数据库中 / 同义变异 / 同源蛋白 / 反式排列 / 重复变异 / 剪接无影响 |

> 各基因的具体强度拆分、阈值与✅条件以 `knowledge-base/VCEP-<基因>.md` 为准，勿直接用上表通用含义做基因特异性判定。

## 5. 数据质量与已知限制（务必遵守）

以下为 VCEP 数据质量核查要点（来源 `VCEP-verification-report-2026-06-14.md` 与 `审查报告_E-P.md`，二者未随包提供，要点摘录如下）：

- **GN 编号历史错配**：曾有 5/5 抽检 GN 编号与基因名称系统性错配（如 GN021=ACADVL 而非 COL1A1）。**使用 GN 编号前必须与基因对照确认**。
- **无 VCEP 规范的基因**：COL1A1、TSC2、LMNA 等在 ClinGen CSpec 无独立 VCEP 规范，本地也无对应文件；查询此类基因时须如实说明，不得伪造规则。
- **本地缺失项**：部分基因规范缺少 VCEP Specifications 前言、组合规则（Rules for Combining Criteria）及"不适用"证据码的原因说明（如 SCN8A 的 PVS1 p.Thr1582 NMD 边界、PM5_Strong 与 PM1 互斥规则）。判读需补充时应提示用户核对官网。
- **审查失败文件**：历史审查记录（`审查报告_E-P.md`，未随包提供）指出 7 个缺失"不适用证据码"章节的文件（FBN1、GJB2、KCNQ4、MYO15A、MYO6、MYO7A、OTOF），使用这些基因时对不适用证据码的判断需谨慎。
- **数据时点**：本地数据截至 2026-06-13；若用户要求最新版本或提及官网更新，建议以 cspec.genome.network 在线文档复核。

## 6. 边界与免责

- 本 Skill 输出为**变异评级的信息检索与判读辅助**，不构成临床诊断、治疗或遗传咨询的最终建议。
- 涉及医学/遗传咨询内容时，应提示用户：最终评级以 ClinGen 官方最新版本、实验室 SOP 与持证遗传咨询师/临床医生判断为准。
- 若用户要求用于临床决策或对某患者个体评级，应说明局限并建议结合官方源复核。
