# PP4：表型/家族史高度特异性证据

## 定义（原文）

PP4：变异携带者的表型或家族史高度符合某种单基因遗传疾病。

## ⚠ 遗传方式前置判定（硬步骤，v1.1.0 新增，表型判定前提）

**判定 PP4 前，必须先调用 `arad-inheritance-judgment` 子技能确认该变异的遗传方式（AD / AR / X连锁 / 无法推断），禁止默认。** 遗传方式用于核验适用情况第 4 条"家族史与疾病遗传方式一致"，以及判断表型是否符合该基因对应疾病的遗传模式。无法推断时写"无法推断"，不得擅自假设。

> 遗传方式以 ClinVar 患者基因型 + PubMed 报道 + GenCC MOI 三方交叉为准，ARAD 为辅助检索工具（见 arad-inheritance-judgment 技能）。

## 适用情况（指南解读 slide 54；变异解读查询路径 5.5.6）

1. 临床检测灵敏度高，大多数带有该基因致病突变的患者都被检测为阳性（如肝豆状核变性 ATP7B）；
2. 患者有某种明确的综合征症状，与其他临床表现几乎无重叠；（查 OMIM 该基因对应疾病临床表型）
3. 该基因通常不存在太多良性变异（可通过外显子组等人群测序确定的良性变异）；
4. 家族史与疾病遗传方式一致；
5. 患者有某种明确临床症状，再结合生化等其他临床证据明确确定为某种疾病时，可上调至 **PP4_Moderate**。

## 不适用情况

- 基因异质性表型：如智力发育障碍、心肌病、乳腺癌、耳聋、无特定脑电图模式的癫痫发作、脑胼胝体细微异常等，不使用该证据；
- 该证据**不能用于二次发现的变异分类**。

## 特异性反证检查（强制，启用 PP4 前必须回答，防"表型相似"误当"表型特异"）

**在启用 PP4 前，须逐条核验下列反证；命中任一条则 PP4 不可用或须大幅降权：**

1. **该疾病是否多基因异质**（表型可由多个基因引起）？是 → PP4 不可用或须降权。
   - 反证清单（本次复盘被证伪的案例，作为判例参考）：HPS 十余亚型（HPS3 不可用）、全色盲 6 基因（CNGA3 不可用）、MADD（ETFDH 不可用）、原发性高草酸尿症 3 基因（GRHPR 不可用）、ARPKD/纤毛病（PKHD1 不可用）、XP/FA 谱系广（ERCC4 不可用）、新生儿胆汁淤积（SLC25A13 不可用）、溶血/黄疸（G6PD 不可用）。
2. **该基因是否人群良性变异极多**？是 → 不可用（例：PKHD1 为最大基因之一 67 外显子，人群良性变异极多）。
3. **该表型是否单一基因高度特异**（如 FVII:C<1 孤立性低 FVII、低游离肉碱 C0）？是 → 可 PP4_Supporting，个别明确综合征可达 Moderate。
4. **该表型能否被本基因特异性证据（如反式 PM3、REVEL PP3）替代**？**能用强证据（PM3/PP3/PS3）时，不得以 PP4 弱码顶替**（以弱代强违规，见 HELXB/SLC22A5-51 教训）。

> **铁律**：PP4 只在表型对**单一基因高度特异**时才启用；对遗传异质性疾病，PP4 一律不用。启用后仍须在输出中写明"该表型对本基因的特异性依据（查 OMIM 临床表型/文献）"。

## 跨技能调用：疾病/表型通道（NCBI Books 等，v1.3.0 新增）

> **本技能判定依赖"疾病表型/外显率/发病率"时，须调用 `ev-disease-info` 子技能获取结构化疾病信息（基因-疾病有效性、表型谱、外显率、发病率）。** `ev-disease-info` 提供 NCBI Books (GeneReviews) / ClinGen / PubMed 通道（`python main.py books "<标准疾病名>"` / `medgen` / `clingen`）：

1. **表型特异性依据（PP4 核心）**：判定"该表型对单一基因高度特异"时，用 `ev-disease-info` 的 **books** 子命令查 NCBI Books (GeneReviews) 该疾病章节的表型描述，与受检者表型比对；同时可经 **medgen** 做表型标准化与特异性判定（关联疾病数），交叉验证表型唯一指向本基因。
2. **外显率 / 发病率**：判断"临床检测灵敏度高 / 高外显"（适用情况 1、5）时，用 `ev-disease-info` 查该疾病外显率 / 发病率（Books penetrance 章节优先）。
3. **防"表型相似误当表型特异"**：用 `ev-disease-info` 的标准疾病名（而非口语化表型）进入查检，减少多基因异质表型的误判；多基因异质反证（特异性反证检查第 1 条）仍须主动排查。
4. **通道边界**：`ev-disease-info` 是疾病信息的结构化工具，**变异身份归一化不在此**（主入口 `ev-variant-standardization`）；本技能只取疾病/表型/外显率数据，不取该工具内部对变异分类的判定。
5. **输出留痕**：凡调用 `ev-disease-info`，在查询路径（输出格式第 3 点）中写明所用子命令（books/medgen/clingen）与标准疾病名。

## 案例（指南解读 slide 55）

患儿男 4 岁，严重呕吐/胃肠炎、酸中毒、昏迷，甘油激酶活性仅对照 5%，高度符合甘油激酶缺乏症。GK c.392del：PP4_Moderate（表型高度符合甘油激酶缺乏症），配合 PVS1、PM2_Supporting，评为致病。

## 输出格式（强制，本 SKILL 判定完成后必须按此输出）

每个证据码判定完成后，**必须**按下述三点完整输出；缺一不可，查不到的数据明确写 **"查不到"**，严禁用本 SKILL 内的举例数据或推测代替。

### 1. 证据码 + 对应等级
`[证据码]_[使用等级]`，如 `PM3_Strong`、`PP3_Moderate`、`PM2_Supporting`。未成立则写"本证据不成立/弃用"。

### 2. 支持该等级使用的规则性数据内容 + 定级规则
- 写明支撑该等级判定的**具体数据值**（如人群频率、REVEL 分数、反式例数、对照数目、OR 值、分离次数等）；
- 对照本 SKILL 的定级规则/阈值表，说明该数据落在哪个区间/档位，从而定为该等级；
- 即：数据值 → 落入的规则档位 → 所得等级，三步闭环。

### 3. 查询路径
列出本次判定**实际查询过**的数据库链接、文献编号(PMID)及对应链接；**每次查询都必须是真实查询**。
- 数据库：名称 + URL（如 ClinVar、gnomAD、Pubvar、OMIM、HGMD、ClinGen 等）；
- 文献：PMID 编号 + 链接；
- 某项查不到：写 **"查不到"**，不得以举例数据填充。

> **铁律**：本 SKILL 内所有"案例/示例/举例"仅供教学演示，**禁止**作为评级数据套用；评级数据一律来自实际查询，否则该证据码不得计入。
