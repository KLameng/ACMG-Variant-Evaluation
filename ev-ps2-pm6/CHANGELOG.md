# ev-ps2-pm6 CHANGELOG

2026-10-15 description 瘦身整改：version 变更日志从 SKILL.md frontmatter 下沉至此

## v1.1.0

- 新增遗传方式前置判定硬步骤——判定前必须先调用 `arad-inheritance-judgment` 确认该变异的 AD/AR 遗传方式（X连锁/常隐/显性等特殊情形依遗传方式处理），禁止默认 AD 或 AR；遗传方式以 ClinVar 患者基因型+PubMed报道+GenCC MOI 三方交叉为准。

## v1.2.0

- 新增【文献核验+可疑文献上报】强制子步骤（用文献报道新发支撑 PS2 时先核验，未核验到 de novo 不得用 PS2）

## v1.2.1

- 补跨技能引用声明——凡本技能判定依赖文献检索/核验时，须调用 `ev-variant-literature-patient` 完成「可疑文献上报」与按用途差异化提取；本技能 description 显式声明该跨技能依赖，不再隐式引用。

## v1.3.0

- 同技能补齐 BP5（良性 Supporting）判定段——无家族史病例中变异确为新发但疾病已由另一独立机制解释时使用，为 PS2/PM6 的方向性良性镜像（变异解读查询路径 5.5.5 相关条目）。

## v1.4.0

- 修复"PS2 漏计（双亲验证双阴）"（整改 P0-2，实证 var024 NSDHL c.595C>T）——写死：先证者为新发变异 + 双亲验证双亲均未检出该变异（双阴）→ PS2_Moderate 成立；双阴与双阳同属有效验证，不得视为"证据不足"；判定前必须确认是否已做双亲验证——未做 → 标"验证缺失"而非"不成立"；家系三比数据本身即满足 PS2 验证要求，"无文献 de novo 报道"不影响本家系三比成立 PS2。

## v1.4.1（全局维护收敛整改）

- 可疑文献判定完整标准（L1/L2/L3 分级 + 挂载默认可疑 + 强制上报）收敛到唯一权威 `ev-variant-literature-patient`，本技能仅保留按用途定制提取要求，不再内嵌重复完整段。
