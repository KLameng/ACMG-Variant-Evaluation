# PP2：错义基因中新错义变异证据

## 定义（原文）

PP2：对某个基因来说，如果这个基因的错义变异是造成某种疾病的原因，并且这个基因中良性变异所占比例很小，在这样的基因中所发现的新的错义变异。

## 操作步骤（指南解读 slide 52；变异解读查询路径 5.3.2.3）

1. 错义突变是该基因**常见的致病机制**；
2. 参考 gnomAD（ExAC）数据库中的 **z 值 > 3.09**（z 值是针对错义突变的预计值，z 值 >3.09 认为错义突变可能是该基因主要致病机制，该基因错义变异适用于 PP2）；
3. 良性错义变异所占比例很低。

> **⚠ 文献核验 + 可疑文献上报（引用唯一权威，PP2 凡依赖文献/VCEP 规则判定"错义为主要机制""良性错义比例低"时必须执行）**
> **当 PP2 的"错义为主要致病机制""良性错义比例低"引自文献或 ClinGen VCEP 规则时，须调用 `ev-variant-literature-patient` 完成「可疑文献上报」判定（L1/L2/L3 分级 + 挂载默认可疑 + 强制上报的完整判定标准，唯一以该技能为准）；纯 gnomAD z 值数据库判定（query_constraint.py）不触发此核验。**

> 以下情况不适用（变异解读查询路径 列有"不适用"清单，按 变异解读查询路径 原文核对）。

### mis_z 取数通道（强制，gnomAD constraint 官方查询）

PP2 的错义 z 值（mis_z）判定须**真实查询 gnomAD/ExAC 基因约束数据**，不得凭记忆或推断。使用本技能配套的 `query_constraint.py`（gnomAD 官方 GCS 公共存储桶，与 gnomAD 浏览器同源，无需 API 认证，仅依赖 Python 标准库）：

```bash
python query_constraint.py <基因符号>      # 查询全部三套数据（v4.0 + v2.1.1 + ExAC RMC）
python query_constraint.py <基因符号> --v4  # 仅 gnomAD v4.0
python query_constraint.py <基因符号> --v2  # 仅 gnomAD v2.1.1
```

- **v4.0 关键字段**：`mis.z_score`（missense Z-score，与 gnomAD 浏览器同源）
- **v2.1.1 关键字段**：`mis_z`（canonical 转录本优先）
- **判定**：`mis_z > 3.09` → 满足 PP2 第 2 条；`mis_z < 3.09` → 不满足 PP2。
- **注**：v4 与 v2 的 Z-score 可能不同（样本量差异），以评估时选用版本为准，两套都查并记录。

### 判例（实测数据，可复现）

- **F7（凝血因子 VII）**：gnomAD v4.0 **mis.z_score = 0.361**；v2.1.1 **mis_z = 0.320**。**均远 < 3.09** → PP2 第 2 条不满足，且存在 rs6046 等常见良性错义多态 → **PP2 不适用**。此为该基因 PP2 判定的实证依据。

### 基因特异性不适用清单（据真实查询补充，F7 等凝血因子基因 PP2 不适用）

**存在大量良性错义多态性变异的基因，PP2 不适用**（第 3 条"良性错义比例很低"不满足）。典型如凝血因子基因：

- **F7（凝血因子 VII，AR 缺乏症，OMIM 227500）**：存在 **rs6046（p.Arg413Gln，曾称 p.Arg353Gln）**、p.Arg353Gln 等多个**常见良性/多态性错义变异**，良性错义变异比例**不低** → **PP2 不适用**。
  - 佐证：F7 突变谱以错义为主（PMC10531009：37 例中 16 个错义占 43.2%，为最常见类型），但因存在常见良性多态，**"良性错义比例低"这一条不满足**；
  - ClinGen **Coagulation Factor Deficiency VCEP**（凝血因子缺陷专家小组）对同类凝血因子基因 **F8 明确 PP2 = Not Applicable**；F7 作为同一专家小组负责基因，PP2 同样不适用。
- 判定提示：对凝血因子基因（F7/F8/F9/F10/F11 等）及存在高频良性错义多态的基因，**PP2 默认不适用**，除非有基因特异性证据证明良性错义比例确实低。

## 自检清单

- [ ] 变异为错义。
- [ ] 已确认该基因错义为主要致病机制。
- [ ] **已用 query_constraint.py 真实查询 gnomAD v4/v2 的 mis_z，并记录数值**（v4 `mis.z_score` / v2 `mis_z`）。
- [ ] gnomAD/ExAC 错义 z 值 >3.09（实测数据，非推断）。
- [ ] 良性错义变异所占比例很低。
- [ ] **已核对基因特异性不适用清单：该基因是否存在大量良性错义多态（如 F7 的 rs6046 p.Arg413Gln、p.Arg353Gln 等），是则 PP2 不适用。**
