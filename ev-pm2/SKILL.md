# PM2：正常人群数据库未见 / 极低频证据

## 定义（原文）

PM2：ESP 数据库、千人数据库、EXAC 数据库中正常对照人群中未发现的变异（或隐性遗传病中极低频位点）。

> ClinGen SVI 工作组建议将标准 PM2 的权重从中等强度**降低到支持水平（PM2_Supporting）**。变异解读查询路径 修订（20200904）：PM2 改为 **PM2_Supporting**。
>
> **⚠ 永久固定（v1.4.0，2026-10-15 用户拍板确认）**：PM2 **永久固定为 `PM2_Supporting`**（除非 ACMG/ClinGen 指南更新），**不得因频率更低或数据更足给 `PM2_Moderate`/`PM2_Strong`**；同码在收尾分值表（acmg-conflict-summary-output）只按 Supporting(+1) 计，不取更高档。

> **⚠ PM2 强度裁定（领域拍板，2026-10-15）**：PM2 **永久固定为 `PM2_Supporting`**（除非未来 ACMG/ClinGen 指南更新，现版本一律按 Supporting 强度处理，不降级、不升档争议）。**两种评级结算方式（经典联合规则 Table5 + Tavtigian 分值）均以证据等级（VeryStrong/Strong/Moderate/Supporting）为统一量纲**：`PM2_Supporting` 即 Supporting，计入 Supporting 桶/分值，**不因码属 PM 类而打折、也不升档为 Moderate**。证据码的升降级对应的是"最终使用等级"，与码前缀基线解耦（引擎 `acmg_combine.py` 已按此实现：PM2@Supporting → Supporting 桶/SU=1）。

## ⚠ 遗传方式前置判定（硬步骤，v1.2.0 新增，阈值选择前提）

**判定 PM2 前，必须先调用 `arad-inheritance-judgment` 子技能确认该变异的遗传方式（AD/XL 或 AR），禁止默认。** PM2 阈值（通用与特异性）均区分 AD/XL 与 AR，遗传方式选错直接导致阈值错用：

- **AD/XL**：通用阈值 <0.0005（指南解读）或 AF=0（变异解读查询路径 20200904）；特异性阈值如 RASopathy=Absent、CDH1/PTEN<0.001%、AD-HL<0.002%、心肌病<0.004%；
- **AR**：通用阈值 <0.001（指南解读）或 AF<0.01%（变异解读查询路径 20200904）；特异性阈值如 AR-HL<0.007%、PAH<0.02%；
- **无法推断**：写"无法推断"，按证据不足处理，不得擅自假设 AD 或 AR 套错阈值。

> 遗传方式以 ClinVar 患者基因型 + PubMed 报道 + GenCC MOI 三方交叉为准，ARAD 为辅助检索工具（见 arad-inheritance-judgment 技能）。

## 操作步骤

### 第 1 步：查频率
- 在 Pubvar 网址输入染色体位点位置进行检索，如 16:2153747。https://www.pubvar.com/
- 同时查 1000G、gnomAD、ESP。
- **取数优先级（v1.1.0）**：优先 gnomAD（v2/v4 全人群 + 东亚 EAS 亚群），再查 1000G/ESP 交叉核对；多库结果须一致，不一致时以数据质量最高者为准并在记录中标注。

### 第 2 步：按大多数遗传病通用阈值判定

- 指南解读 口径：正常人群数据库频率 **< 0.0005（AD/XL）或 < 0.001（AR）**。（⚠ 内部口径：ACMG 2015 对 PM2 无具体数值、ClinGen SVI 亦无该通用数值；存在基因/疾病特异性阈值时必须优先用特异性阈值。）
- 变异解读查询路径 口径（20200904 修订）：**AF=0（显性）；AF < 0.01%（隐性）**。（同为内部口径）
- 两者不一致时，按本实验室现行 变异解读查询路径 口径执行，并在记录中标注版本。

### 第 3 步：查基因/疾病特异性 PM2 阈值（变异解读查询路径 p7 表，版本 20200904）

> **来源锁定**：下表基因/疾病特异性 PM2 阈值取自《变异解读查询路径》p7 表（**20200904 修订版**，与第 13/20/35 行通用阈值口径同版本）+《指南解读》slide 43。引用下表数值时须在输出标注"特异性阈值来源=变异解读查询路径 p7 表（20200904）+ 指南解读 slide 43"，不得混用其他版本。

| 疾病或基因 | PM2 threshold |
|---|---|
| RASopathy - AD | 所有人群数据库完全缺失（0 等位，ClinGen 口径） |
| CDH1（胃癌/乳腺小叶癌）- AD | <0.00001（0.001%）；亚群 ≥2 等位时 <0.00002（0.002%）；gnomAD 覆盖度 ≥30× |
| PTEN（错构瘤肿瘤综合征）- AD | <0.00001（0.001%）；亚群多等位时 <0.00002（0.002%） |
| Hearing loss - AD | <0.00002（0.002%） |
| Cardiomyopathy - AD | <0.00004（0.004%） |
| Hearing loss - AR | <0.00007（0.007%） |
| PAH（苯丙酮尿症）- AR | <0.0002（0.02%） |

存在基因/疾病特异性阈值时，以特异性阈值为准。

> **⚠ 文献核验 + 可疑文献上报（引用唯一权威）**
> **PM2 主判据是人群频率数据库（Pubvar/gnomAD/1000G/ESP），一般不依赖患者文献。当特异性 PM2 阈值引自文献/ClinGen VCEP 规则、或频率数据质量核验引用 ClinVar 提交注释文献时，须调用 `ev-variant-literature-patient` 完成「可疑文献上报」判定（L1/L2/L3 分级 + 挂载默认可疑 + 强制上报的完整判定标准，唯一以该技能为准）；纯数据库频率判定不涉及患者文献，正常执行，不触发核验。**
> **⚠ 按用途定制提取（v1.3.0 全局，PM2）：本证据码以频率数据库(gnomAD/ExAC/1000G)为主，一般不提取患者文献；仅当使用基因/疾病特异性阈值时，须核验该阈值出处文献是否真实存在并给出链接；频率数据质量差的位点须标注。纯数据库频率判定不涉及文献提取，直接取 AF 值。关键字段提取不到，标"查不到"，不得凭推测填充。**


### 第 3.5 步：阈值选择优先级（v1.1.0 强制，写死）

> **PM2 判定的核心不是"用不用"，而是"阈值是否选对"。** 判定 PM2 前必须按下列顺序选择正确的阈值，不得一律套通用阈值：

1. **先查该基因/疾病是否有特异性阈值**（本表、ClinGen VCEP 规则、专家面板特异性 PM2 阈值）；
2. **存在特异性阈值 → 一律优先用特异性阈值判定**，不得用通用阈值替代（例如 AR-HL 用 0.007% 而非通用 0.1%；PTEN 用 0.001% 而非通用阈值）；
3. **无特异性阈值 → 才用通用阈值**（AD/XL <0.0005、AR <0.001，按本实验室现行口径）；
4. **阈值不一致时**：以基因/疾病特异性阈值为准；若同时存在通用与特异性口径，记录两者并说明取特异性阈值的依据。
5. **记录要求**：判定 PM2 时必须在输出中写明"所用阈值（通用/特异性）"及"该阈值来源"，查不到特异性阈值时写"查不到特异性阈值，用通用阈值"。

> **🔧 确定性定档（acmg_evidence.py，替代手工查表）**：AF→PM2 档位统一用 `scripts/acmg_evidence.py` 的 `pm2_band(af, mode, gene_specific)` 确定性输出（含 AD/XL 0.0005、AR 0.001 通用阈值与特异性阈值优先）。用法：`python acmg_evidence.py pm2_band <AF> <AD|AR>`；AF 取不到写"查不到"，不得默认满足 PM2。

> **铁律**：基因/疾病特异性阈值优先于通用阈值；不得因"总分已够/已有强证据"而剔除满足阈值的 PM2（PM2 是独立证据维度，满足标准即应计入）。

### 第 4 步：频率数据质量核验（v1.1.0 强制）

> 频率数据质量差的位点，其频率不可靠，不得直接作为 PM2 依据。核验并处理：

1. **查数据质量标记**：在 gnomAD 查看该位点的数据质量（QC 标记：低质量位点、呼叫质量差、覆盖不足、过滤等）；ClinVar 提交注明"frequency data unreliable / metrics indicate poor data quality"时尤其警惕。
   - 例：GRHPR c.864_865del 在 gnomAD 为**低质量位点**（ClinVar Invitae 注明"frequency data considered unreliable, poor data quality at this position"），其频率不可直接采信。
2. **处理规则**：
   - 位点数据质量差 → **不得仅凭该频率定 PM2**；须改用高质量数据库交叉核对（1000G/ESP/其他队列）；
   - 若高质量库仍无法确认频率 → 标注"频率数据质量差，PM2 判定受限/降权"，**不得把"查不到可靠频率"默认为"满足 PM2"**；
   - 若该位点同时有健康纯合子/较高频率（如 SPATA7 jMorp 12 纯合子）→ 属**良性反证**，PM2 前提（罕见）被削弱，须按反证降权或弃用，并在记录注明。
3. **记录要求**：判定 PM2 时须写明"所用频率来源 + 该位点数据质量标记 + 是否采信"，数据质量差时写"查不到可靠频率，PM2 受限"。

## 输出格式（强制，本 SKILL 判定完成后必须按此输出）

每个证据码判定完成后，**必须**按下述三点完整输出；缺一不可，查不到的数据明确写 **"查不到"**，严禁用本 SKILL 内的举例数据或推测代替。

### 1. 证据码 + 对应等级
`[证据码]_[使用等级]`，如 `PM3_Strong`、`PP3_Moderate`、`PM2_Supporting`。未成立则写"本证据不成立/弃用"。

### 2. 支持该等级使用的规则性数据内容 + 定级规则
- 写明支撑该等级判定的**具体数据值**（如人群频率、REVEL 分数、反式例数、对照数目、OR 值、分离次数等）；
- 对照本 SKILL 的定级规则/阈值表，说明该数据落在哪个区间/档位，从而定为该等级；
- 即：数据值 → 落入的规则档位 → 所得等级，三步闭环。

### 3. 查询路径
列出本次判定**实际查询过**的数据库链接、文献编号(PMID)及对应链接；**每次查询都必须是真实查询**。
- 数据库：名称 + URL（如 ClinVar、gnomAD、Pubvar、OMIM、HGMD、ClinGen 等）；
- 文献：PMID 编号 + 链接；
- 某项查不到：写 **"查不到"**，不得以举例数据填充。

> **铁律**：本 SKILL 内所有"案例/示例/举例"仅供教学演示，**禁止**作为评级数据套用；评级数据一律来自实际查询，否则该证据码不得计入。
